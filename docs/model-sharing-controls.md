# 模型外发控制

在工作台的“系统设置”中，打开“当前会话的模型外发设置”，选择发送范围并点击“保存当前会话外发设置”。设置只作用于当前会话；切换会话时会读取该会话已保存的策略。分析运行期间不能修改，本轮使用开始时已保存的设置。

## 结果与图片分别控制

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 统计结果发送方式 | 仅发送汇总结果 | 向模型提供经过筛选的汇总结果，个体结果保留在本机。 |
| 不向模型发送的敏感列 | 空列表 | 按指定列名屏蔽结果预览中的相应列；这份清单不构成匿名化保证。 |
| 发送本机分析结果图 | 关闭 | 自动生成的 R 分析图须另行允许，结果发送方式不会自动打开该开关。 |
| 发送我主动附加的图片 | 开启 | 用户主动附加的图片独立控制；关闭时，含待发送附件的提问会被拒绝，移除附件后可继续发文字。 |

“发送去标识的个体结果”模式保留个体层面的数值，用于解释预测、排序、差异等结果；指定敏感列被隐藏，识别出的身份 ID 使用临时别名。它保留统计信息，也保留部分个体信息，不能称为完全匿名。需要更少外发内容时，可选择默认的汇总结果模式。

敏感列每行填写一个精确列名，也可从当前已检查的字段添加。保留列名原有大小写和有意义的首尾空格，不应把“选择了敏感列”理解为已经找全所有身份信息。该设置控制模型视图，不会删除本机原始列、修改计算输入、改变系数或覆盖完整结果。

## 原图与自由文本的边界

开启结果图或主动附件发送后，发送的是原图，图中的姓名、标签、编号及其他文字不保证脱敏。结果表的敏感列过滤不会修改图片像素。只有确认图中内容适合外发时才开启相应开关，不能把允许发送的原图称为匿名图。

你在输入框中填写的文字仍会发送给模型。自由文本可能直接或间接包含身份信息，应用不能保证任意文本都被匿名化；自动结果预览的过滤也不意味着手工文字已经接受同等处理。应按研究需要选择文字、个体结果和图片的发送范围。

## 历史、恢复与本机结果

保存新策略后，后续模型请求按当前策略重新处理历史工具结果和自动图反馈。收紧设置会使不符合新策略的旧预览或图片不再重放；此前已经发送的内容无法通过本机设置撤回。

策略变更会使旧的语义压缩缓存（compaction）和上一轮推理缓存失效，避免沿用在另一发送范围下形成的上下文。缓存复用还须匹配当前策略。手动载入或自动恢复会话时保留已保存的外发策略，并清除旧缓存；没有该字段的旧会话使用默认策略。清空对话或回退分析状态不会自动切换到更宽松的策略。

原始数据文件、冻结的分析输入、本机 R 执行、完整表格、模型、图片和本地回执继续保留在本机。外发控制建立面向模型的视图，不重写这些产物，也不更改 API Key。统计执行与模型解释因此可能使用不同的信息范围；未发送的详情不能被模型解释为不存在。

## 接口与实现位置

`GET /api/session/<sid>/model-sharing` 读取当前策略；`POST` 保存完整策略对象，返回 `ok` 与 `policy`。非法设置返回 400，分析或会话变更运行中返回 409。设置与手动保存、自动保存一起持久化，尚无消息的会话也可保存非默认策略。

策略字段为 `result_mode`（`summary_only` / `deidentified`）、`sensitive_columns`、`send_result_images`、`send_attached_images` 和版本号 `version=1`。相关实现为 [策略合同](../agent/analysis/model_sharing.py)、[模型视图过滤](../agent/analysis/model_egress.py)、[设置 API](../api/models.py) 和 [会话保存与恢复](../api/saved_sessions.py)。
